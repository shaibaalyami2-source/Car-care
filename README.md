# CRM · نظام إدارة خدمات النظافة — الإصدار 3.0

## النشر على Cloudflare Pages
1. Cloudflare ← Workers & Pages ← Create ← Pages ← **Upload assets**.
2. ارفعي محتويات هذا المجلد كما هي (index.html و sw.js و manifest.webmanifest و config.js و _headers ومجلد icons).
3. بعد النشر افتحي الرابط من الجوال واضغطي «تثبيت التطبيق» — يعمل بعدها بدون إنترنت.

## التخزين على Google Sheet (مبدئي حتى بناء الخادم)
1. أنشئي ملف Google Sheet جديد (أو استخدمي الملف المجهّز).
2. الإضافات ← Apps Script ← الصقي محتوى `Code.gs` ← حفظ.
3. اختاري الدالة `setup` ← تشغيل ← وافقي على الأذونات. يظهر مفتاح الوصول في تبويب «إعداد».
4. نشر ← نشر جديد ← تطبيق ويب: التنفيذ باسم «أنا»، والوصول «أي شخص» ← انسخي رابط تطبيق الويب.
5. في النظام: الإعدادات ← المزامنة السحابية ← الصقي الرابط والمفتاح ← ربط. ثم «ربط جهاز آخر» لجوالات الفريق (رمز QR).
6. اختياري: ضعي الرابط في `config.js` (endpoint) لتصل طلبات «بوابة العملاء» من جوالات العملاء مباشرة إلى الملف، واجعلي `demo: false` عند التشغيل الفعلي.

## ملاحظات
- خط Bahij Janna: ضعي ملفاته (Bahij_Janna-Regular.woff2/.ttf و Bahij_Janna-Bold.woff2/.ttf) في مجلد `fonts/` بجانب index.html إن كانت لديكم رخصته؛ وإلا يُستخدم Readex Pro تلقائيًا.
- الصلاحيات تُطبّق داخل الواجهة؛ الحماية الكاملة للبيانات تكون مع الخادم الخاص (Backend).
- الخرائط من OpenStreetMap، وحدود الأحياء من Who's On First (حي العزيزية تقريبي).
- الترجمة: عبر Google (LanguageApp) عند الربط بالملف، وإلا MyMemory.
